# Quick Response Electrical Service (Static Bootstrap Rebuild)

This repository contains a **static** rebuild of the current production site at `http://quickresponseelectricalservice.com/` using **HTML + JavaScript + Bootstrap**.

## Pages

- `index.html`
- `about.html`
- `recent_work.html`
- `contact.html`
- `electrical-wiring-installation.html`
- `emergency-electrical-repair-services.html`
- `electrical-maintenance-services.html`
- `24-7-electrical-service.html`

## Assets

- `assets/css/styles.css`
- `assets/js/main.js`
- `assets/img/` (logo + images pulled from the existing site)
- `assets/favicon/`

## Running locally

Because this is static HTML, you can open `index.html` directly in a browser, or serve the folder with any simple static server.

## Content constraints

All business content (services, descriptions, contact info) was taken from the existing production site. No new services, pricing, or contact details were invented.
